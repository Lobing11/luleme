# 鹿了么 v1.1.0 版本更新说明

> **版本号**：`1.1.0`（versionCode `1000100`，buildVersion `2`）
> **发布日期**：2026-10-25
> **构建产物**：[鹿了么-v1.1.0-release未签名版.hap](<../dist/鹿了么-v1.1.0-release未签名版.hap>)（261,893 字节，release + 未签名）
> **包名**：`com.luleme.app`　**SDK**：compatible/target `6.1.1(24)`
> 明细文档：[UI优化记录-第二轮.md](UI优化记录-第二轮.md)、[Bug修复记录-首页数据不刷新.md](Bug修复记录-首页数据不刷新.md)

一句话概括：**这是一次「看得见手感」的版本**——底部悬浮导航栏不再错位，切 Tab 立刻响应并带过渡动效，日历能正常前后翻月，统计数字不再恒为 0，首页补记的历史记录保存后立即出现。

## 一、界面与交互（用户可感知）

### 1. 底部悬浮导航栏恢复正常

- 修复「药丸右侧被截断、多出一个圆形设置按钮、设置二字竖排」的显示异常：根因是给 `HdsTabs` 配了收起的 `miniBar` 形态，系统把胶囊栏与迷你栏并排布局，胶囊被压到只剩 42px 宽。已移除 `miniBar`，恢复系统默认浮动药丸（实测居中、三项均分）。
- 底栏图标由 emoji 换成 `SymbolGlyph` 符号（日历 / 统计 / 设置），选中态与深色模式一致。

### 2. Tab 切换更「跟手」，并有转场动效

- 改为 **点击即切换状态**：底栏高亮与顶部标题在同一帧变化，不再等切换动画结束后才更新（旧逻辑走 `onChange`，比点击晚约 150ms）。
- 内容区加入 **220ms 淡入 + 6vp 上浮**（FastOutSlowIn），切页不再「生硬闪现」。
- 增加 **120ms 防连点**，快速连点不会错位；三页 `cachedMaxCount(3)` 驻留，来回切换不重建页面。
- 渲染与数据解耦：切换 Tab 不再触发任何数据库读取。

### 3. 三页头部统一，去掉重复入口

- 首页头部不再出现「统计 / 设置」文字入口（与底栏重复），标题、高度（48vp）、毛玻璃背景三页一致。

### 4. 日历

- 修好热力图 **Grid 未设高度占满 2305px**、把空态与「＋ 记一笔」按钮顶出屏幕的布局 Bug。
- 月份切换箭头可正常前进 / 后退；到达当前月后右箭头置灰并禁用（不再「点了没反应」）。
- 换月后高亮与计数不再跨月残留（`ForEach` key 改为 `年-月-索引`，网格数据改为 `@Prop` 驱动）。
- 「今天」用描边标识，与「有点击记录的日子」的粉色深浅区分开。

### 5. 统计

- 六张指标卡（本月次数 / 当前连续 / 总次数 / 最长间隔 / 平均间隔 / 距上次）改为统一组件 `StatTile`，**不再恒显示 0**（此前只有趋势图正确）。
- 趋势图颜色改为读取主题色资源，深色模式不再发灰；每行卡片按 `layoutWeight(1)` 等分，不再「一行只剩第一张」。

### 6. 设置

- 新增 **沉浸光感 · 材质档位**：自适应（默认，跟随系统策略）/ 精致 / 均衡 / 柔和，四档分段控件，通过 HDS `systemMaterialEffect` 应用到导航栏与底栏；不支持材质的设备自动降级。
- 「材质档位」行改为「标题 + 副标题在上、四档控件在下」，长文案不再被裁掉；说明文案改为「根据设备性能自动调整视觉效果」。
- 生物识别不可用时整行置灰且不可点击（此前看起来能点）；分割线统一内缩 `16vp`，与文字左边缘对齐；开关不再溢出卡片右缘。
- 「关于 → 版本」改为**从 bundle 自动读取**，不再手写 `v1.0.0`（本次已显示 `v1.1.0`）。

### 7. 其他一致性

- 空状态统一为 `EmptyState` 组件（日历空态 / 当日无记录 / 统计无数据），文案与留白一致。
- 页面级间距、圆角、行高、底栏留白收敛到 `DesignTokens`，避免各页「各调各的」。
- 导航返回按钮统一为 `NavIconButton`（圆形按压态、48vp 触控热区）。

## 二、Bug 修复清单（含根因）

| # | 现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 底栏被截断、出现重复的设置圆钮、「设置」竖向换行 | `HdsTabs.barFloatingStyle().miniBar` 让胶囊栏与迷你栏并排，胶囊被压缩到 42px | 移除 `miniBar`，保留单一胶囊栏 |
| 2 | 所有统计数字恒为 0 | `@Builder` **参数按值传递**，`load()` 异步返回后 builder 子树不重建 | 抽 `StatTile`（`@Component` + `@Prop`） |
| 3 | 日历右箭头点了没反应，无法回到当前月 | `enabled` 作为参数传进 `@Builder` 被冻结在首帧 `false`；网格数据用普通成员变量 | 箭头改为读 `@State`；`CalendarHeatmap` 数据源改 `@Prop` |
| 4 | 换月后上月高亮（如 25 号）残留在新月份 | `ForEach` key 只绑了索引/day，节点被复用；网格数据未随月份更新 | key 改为 `年-月-索引`，并驱动 `@Prop` 重算 |
| 5 | **补记「今天之前」的记录后首页不显示**（不重启就一直是 0 / 空态） | 首页只在 `aboutToAppear` / `onPageShow` 读库，而新增/编辑是 NavDestination，`pop()` 不触发 @Entry 的 `onPageShow`；同时 `init()` 未 await 的竞态被空 `catch` 静默吞掉 | 数据层新增写库广播 `subscribe/notifyChanged`，首页订阅后即时刷新；`init()` Promise 化，`refresh()` 异常改为 `console.error` |
| 6 | 编辑记录的日期栏显示「今天 + 当前时刻」，而非记录真实时间 | 日期/时间字符串作为参数传进 `@Builder`，被冻结在首帧 | 拆为零参 `@Builder`（`dateRow()` / `timeRow()`）直读 `@State` |
| 7 | 设置里「应用锁 / 生物识别解锁」副标题不更新（设完 PIN 仍显示「未设置 PIN」） | 同 6，动态文案按值传参 | 改为 `lockSettingRow()` / `bioSettingRow()` 零参 `@Builder` |

## 四、升级与安装

- `versionCode` 由 `1000000` 提升到 `1000100`，可直接覆盖安装升级。
- 本次提供的是 **release 未签名包**，需自行签名后安装：
  - DevEco Studio：Project Structure → Signing Configs → 勾选自动生成签名后 Run；
  - 命令行：用 SDK 内 `hapsigner` 或 `hvigorw --mode module -p product=default assembleHap`（配置好 `signingConfigs` 后再打包）。
- 复现未签名包的方式：把 `build-profile.json5` 的 `signingConfigs` 置空、并去掉 product 的 `signingConfig` 字段，执行
  `hvigorw assembleHap --mode module -p product=default -p buildMode=release`，产物即
  `entry/build/default/outputs/default/entry-default-unsigned.hap`。

## 六、已知遗留

1. `HDS_tabs: ParseProp failed parse property barSideMargin / barBottomMargin`：UIDesignKit 浮动栏对这两个属性的解析告警（既有问题，底栏渲染正常）。
2. 跨零点不会自动把「今日」翻页，需要一次页面交互或重新回到前台。
3. 「清空所有记录」与 PIN 设置流程走同一套刷新机制，但为避免破坏测试数据与锁状态，未做破坏性真机验证。
4. 编辑带备注的旧记录时，备注输入框依赖组件参数刷新，未构造专门用例验证。
