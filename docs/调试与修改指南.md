## 一、DevEco Studio 调试基础

### 1.1 运行与看日志

1. 点顶部绿色 **Run ▶**（或 `Shift+F10`）→ 编译并安装到手机，自动启动。
2. 看日志：DevEco 底部 **Log** 面板（或 `View > Tool Windows > Log`）。
3. 应用内打印日志用 `hilog`（类似 Android 的 Logcat）：

```ts
import { hilog } from '@kit.PerformanceAnalysisKit';

// 在任意方法里加：
hilog.info(0x0000, 'luleme', '我的调试信息：%{public}s', JSON.stringify(某变量));
```

- 在 Log 面板过滤框输入 `luleme` 即可只看你的日志。
- 参数：`hilog.info(domain, tag, format, ...args)`，`%{public}s` 表示普通字符串可打印；敏感数据用 `%{private}s` 会被打码。

### 1.2 断点调试

1. 在代码行号左侧**点一下**打红点断点。
2. 点 **Debug ▶**（虫子图标）运行。
3. 运行到断点会停下，可 **F10 单步 / F8 跳过 / F7 进入**，右侧 Variables 面板看变量值。
4. 注意：断点调试用 Debug 构建即可；部分 UI 回调（如 onClick）断点可能不进，属正常。

### 1.3 快速预览 UI（不用装机）

- 打开 `pages/Index.ets` 等页面文件，点编辑器右上角 **Previewer（预览器）** 标签，可即时预览布局、切换设备/深浅色。
- 预览器对 `expandSafeArea`、状态栏等真机效果模拟有限，最终以真机为准。

### 1.4 命令行抓真机日志（可选）

```bat
D:\Program_Files\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe shell hilog | findstr luleme
```

## 三、手把手示例

### 示例 A：把主色从粉色改成紫色

1. 打开 `entry/src/main/resources/base/element/color.json`
2. 第 8 行附近 `"color_primary"` 的 `"value": "#FF5E7E"` → 改成 `"#7C4DFF"`
3. 打开 `entry/src/main/resources/dark/element/color.json` 同样改
4. `color_primary_soft` 也顺手改浅紫色，如 `#EDE7FF`（浅色）/ `#3A2E55`（深色）
5. 点 Run ▶，完事。按钮、标签选中态、日历高亮都会跟着变。

### 示例 B：给"刷新数据"加调试日志

1. 打开 `pages/Index.ets`，找到 `private async refresh(): Promise<void>`（约 100 行）
2. 在 `this.records = all;` 后面加一行：

```ts
hilog.info(0x0000, 'luleme', 'refresh: 共 %{public}d 条记录', all.length);
```

3. 文件顶部加导入：`import { hilog } from '@kit.PerformanceAnalysisKit';`
4. Run 后打开 Log 面板，过滤 `luleme`，每次回到首页/新增记录都会打印记录条数。

### 示例 C：让日历格子更大一点

1. 打开 `components/CalendarHeatmap.ets`
2. 第 59 行 `.height(44)` → `.height(50)`，第 60 行 `.borderRadius(10)` → `.borderRadius(12)`
3. Run 看效果；不满意继续调。

## 四、改坏了怎么办

1. **Ctrl+Z 撤销**：DevEco 编辑器支持多步撤销。
2. **对比原文**：文档底部附关键文件清单，可对照检查。
3. **建议用 git 管理**（工程已带 `.gitignore`）：
   ```bat
   cd C:\Users\WHO\DevEcoStudioProjects\MasterBate
   git init
   git add -A
   git commit -m "v1.0 基线"
   ```
   以后每次改代码前先 commit，改坏了 `git checkout -- <文件>` 一键还原。
4. **编译报错**：先看报错行号和提示；ArkTS 常见坑：不能用 `any`、对象字面量必须有类型、回调参数要写类型——把报错原文发我最快。
