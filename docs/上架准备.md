# 鹿了么 · 上架准备清单

> 目标平台：华为应用市场（AppGallery Connect）。本应用为**纯本地**应用（无服务器、无账号体系、无网络权限），上架流程相对简单，但仍有硬性材料要求。

## 一、签名与调试

1. **华为开发者账号**（个人即可）：注册并完成实名认证 → https://developer.huawei.com
2. **DevEco Studio 自动签名**：`File > Project Structure > Signing Configs`，勾选 Automatically generate signature，登录华为账号，自动生成调试证书与 Profile。
   - 真机需开启「开发者模式」并在设备登录同一华为账号。
3. **发布签名**（上架前）：在 AppGallery Connect 创建应用后生成正式证书（.p12）、Profile，配置到 `build-profile.json5` 的 `signingConfigs`。
   - 当前 `build-profile.json5` 中 `signingConfigs: []`，签名留空，产物为 unsigned HAP，仅能本地调试。

## 二、上架材料

| 材料 | 说明 | 备注 |
| --- | --- | --- |
| 应用名称 | 鹿了么 | 上架前在华为市场检索是否有同名/近似应用（与「饿了么」谐音，建议同时准备备用名） |
| 应用图标 | 1024×1024 PNG（含前景/背景分层） | **已设计**：粉色渐变 + 白色小鹿剪影 + 小心心（`AppScope/resources/base/media/`），可用 `tools/make_icon.ps1` 重新生成或微调配色 |
| 应用截图 | 至少 3 张（不同分辨率） | 需覆盖首页 / 统计 / 设置，画面健康化 |
| 应用描述 | 中文简介 + 功能介绍 | 定位为「私密健康记录」，避免成人向描述 |
| 隐私政策 | 见下方模板 | 纯本地应用也要提供，重点声明"数据不出设备" |
| 软件著作权 | 可选但强烈建议 | 无软著需提交其他审核材料，周期更长 |
| 年龄分级 | 按指引勾选 | 涉及性健康主题，如实填写 |

> **注意**：本项目不需要 ICP 备案（无域名、无服务器）。若未来增加云同步，则需备案 + 等保等额外合规。

## 三、上架前自查（对照审核要点）

- [ ] `module.json5`：确认未声明 `ohos.permission.INTERNET`（隐私卖点 + 审核加分）
- [ ] 权限最小化：仅 `ohos.permission.ACCESS_BIOMETRIC`（system_grant，无弹窗）
- [ ] 应用锁功能：PIN 加盐哈希存储（非明文），生物识别仅在用户开启后使用
- [ ] 隐私政策文本已就绪且应用内可查（设置页「关于」有说明，可补充完整政策链接页）
- [ ] 备份 JSON 的导出/导入已真机验证
- [ ] 深色模式、横屏（如有）、不同分辨率下界面正常
- [ ] 单元测试通过（`entry/src/test`）
- [ ] 图标、截图、描述已替换为正式素材
- [ ] 版本号：`app.json5` 中 `versionCode`（当前 1000100）/ `versionName`（1.1.0）

## 四、隐私政策模板（纯本地应用适用）

> 以下为可直接使用的精简模板，建议按上架审核要求补充为完整版本。

**鹿了么隐私政策**

1. **数据存储**：本应用的全部记录数据（包括记录时间、心情、备注）仅保存在您设备的本地存储中（应用沙箱内的 SQLite 数据库）。应用不采集、不上传、不共享任何个人数据。
2. **网络权限**：本应用不申请任何网络权限，无法联网。
3. **生物识别**：应用锁的生物识别（指纹/人脸）仅用于本机解锁验证，验证过程由系统完成，应用不存储任何生物特征信息。PIN 以加盐哈希形式存储，不保存明文。
4. **备份**：您可以通过「导出备份」将数据保存为 JSON 文件，或通过「导入备份」恢复数据，文件由您自行保管。
5. **系统备份**：如您开启华为系统云备份，应用数据可能随系统备份机制处理，具体以系统设置为准。
6. **联系方式**：［填写您的联系方式］

## 五、发布流程

1. AppGallery Connect 创建应用，填写基本信息（包名 `com.luleme.app` 需一致）
2. 配置发布证书与签名，本地构建 release HAP（`assembleHap --mode module -p buildMode=release`）
3. 上传 HAP + 素材，提交审核（首次审核一般 1-2 周，含人工内容审核）
4. 审核通过后设置上架时间，正式发布
